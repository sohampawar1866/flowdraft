# Project submission copy

## Project title

FlowDraft — voice-first Gmail for developer updates

## About the project

As a developer, I send four or five short but important updates to my team most days. They are quick to write, but switching between Gmail’s recipient, subject, and message fields—and then manually bolding the key detail—breaks my flow. FlowDraft lets me dictate the whole email with Wispr Flow, say “Hey Wispr, bold the deployment date,” and get a ready-to-review Gmail draft. I check it and send it myself.

## How Wispr Flow is used

I open a new Gmail compose, hold Fn, and dictate the recipient, subject, and message in one pass. In that same dictation, I can say “Hey Wispr” before a formatting request. FlowDraft organizes the text and applies supported formatting; it does not listen to audio or send the email.

## Demo outline

Show a realistic project update being dictated into a new Gmail compose, including a spoken formatting request for one important phrase. Then show the recipient, subject, message, and formatting in the draft. End by reviewing the draft in Gmail; do not send it during the demo.

## Scope note

FlowDraft is a Chrome/Gmail prototype that works with Wispr Flow's inserted transcript. Gmail's page structure is not a stable public extension API, so compatibility may require updates as Gmail changes.
